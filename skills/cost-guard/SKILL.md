# 长任务成本控制

## 先用便宜工具

能用一个 search_knowledge 或 search_tavily 回答的问题，不要调用 deep_research。先判断问题是否需要多来源交叉验证。

## 什么时候值得 deep_research

需要对比三个以上对象、跨多个来源核实，或用户明确要求完整调研报告时再用；调用前把 query 收敛到一句话，避免宽泛关键词导致并行搜索膨胀。

## 什么时候不要用

事实查询、单文档总结、格式转换、简单计算、对已有答案的追问，都不要用。工具失败一次后不要原样重试，先缩小范围或更换检索词。

## 预算意识

注意本轮工具调用次数与费用上限；接近上限时先给阶段性结论，并明确告诉用户还缺什么。
