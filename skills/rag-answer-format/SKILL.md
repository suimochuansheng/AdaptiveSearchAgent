# 内部知识库答案格式

## 结论先行

第一段用一到三句话直接回答用户的问题，不要先复述检索过程。结论里带上关键数字、时间与适用范围。

## 分点展开

需要比较多个对象时用表格，列数不超过五列：对象、关键指标、适用条件、结论。表格前先用一句话说明这张表回答什么问题，表格后补充一句最重要的判断。

## 引用与边界

每个事实性论断后面标注来源编号；知识库没有覆盖的部分明确写“未检索到”，不要用常识补全。最后单列“限制与待确认”，写清时效、口径和缺失信息。

## 长度

默认控制在三百字以内；用户要求详细报告时先给摘要，再展开细节，避免把检索原文整段粘贴。
