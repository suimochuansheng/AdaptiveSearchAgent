# TDM 会话前端 + 审批卡片 —— I3 手动验收步骤清单

> 适用卡：T-demo（G9 车道，仅 `frontend/`）
> 前置：容器 `postgres_dev` / `postgres_test` / `redis_cache` 已运行；仓库根目录执行。
> 机器人可先跑离线自检：`poetry run python "tests/test_agent_cases/TDM-会话前端+审批卡片/tdm_checks.py"`（末行应为 `RESULT: 10 passed, 0 failed`）。

## 0. 起真实后端 + 前端（主环境）

```bash
cd /home/ubhuazhu/dev_pros/AdaptiveSearchAgent
poetry run uvicorn api_main:app --port 8000          # 终端 A
poetry run chainlit run frontend/app.py --port 8001  # 终端 B
```

浏览器打开 <http://localhost:8001>，能看到欢迎页即通过。

## 1. 默认模式仍是 deep_research（旧流程零变化）

打开右上角设置（⚙️），确认「对话模式」为 **deep_research**。
发一句「什么是 LangGraph？」。

- 通过：先出现可折叠「思考过程」Step，再流式出现最终报告，行为与改造前一致。
- 失败：默认值是 conversation，或旧端点提示报错。

## 2. 切到 conversation，发「你好」——流式且整段只出现一次

设置里把「对话模式」切到 **conversation**，发「你好」。

- 通过：回答逐段流式出现；整段文字在页面上**只出现一次**（不能先流一遍、final 又补一遍）。
- 失败：重复整段、空白气泡、或出现「未知错误」。

## 3. 注入假 interrupt 帧，检查审批卡片四要素 + 两个按钮

真实后端还没有审批中断，用假 SSE 后端注入（**不碰 `api_main.py`**）：

```bash
# 终端 C：假后端 :8002（收到含「深度调研」的消息就吐 interrupt）
poetry run python "tests/test_agent_cases/TDM-会话前端+审批卡片/fake_sse_server.py"

# 终端 D：第二个前端实例 :8003，指向假后端
FASTAPI_BASE_URL=http://127.0.0.1:8002 \
  poetry run chainlit run frontend/app.py --port 8003
```

打开 <http://localhost:8003> → 模式切 **conversation** → 发「跑个深度调研」。

- 通过：先流出一小段文字 + 「思考过程」里出现「调用工具: deep_research」，
  随后弹出审批卡片，含且仅含：
  **工具名** `deep_research`、**参数摘要** `query=量子计算最新进展&max_results=5`、
  **预估成本** `0.10 元`、**剩余预算** `2.00 元`、**到期时间**（未来 10 分钟内的 ISO 时间）；
  按钮为「✅ 同意执行」「❌ 拒绝」，且**没有**「记住选择」类按钮。
- 失败：缺字段、按钮缺失、页面卡住。

## 4. 点「拒绝」——走 resume(reject)，界面提示已拒绝且会话可继续

在步骤 3 的卡片上点「❌ 拒绝」，同时看浏览器 DevTools → Network（或后端日志）。

- 通过：出现且仅出现一次 `POST .../resume`，body 的 `decision="reject"`；页面出现
  「🙅 已拒绝执行，本次调用未被发起。」；随后流式给出降级回答；同一会话再发消息不出现 409。
- 失败：不发 resume、resume 超过一次、或拒绝后同会话 409。

## 5. 点「同意执行」——404 时显示「审批功能未启用（等待 T9-2）」，不崩

（可选）先重启终端 D 的前端让页面干净，再重复步骤 3，点「✅ 同意执行」。

- 通过：Network 中出现 `POST http://127.0.0.1:8002/chat/conversation/<thread_id>/resume`，
  Request Payload 含 `approval_id`、`decision="approve"`、`request_id`（标准 uuid4）、`token`；
  后端 404 后页面出现「⚠️ **审批功能未启用（等待 T9-2）**」，页面不崩、可继续输入。
- 失败：抛异常堆栈、转圈卡死、或没有任何提示。

## 6. 超时自动拒绝（验收时临时把 `APPROVAL_TIMEOUT_SECONDS` 压到 2 秒）

再发一次「跑个深度调研」，**不点任何按钮**，等超时。

- 通过：出现「⏰ 审批超时（... 秒），已自动拒绝，本次调用未被发起。」；随后同样发出一次
  `POST .../resume`（`decision="reject"`）；后端状态回到 `completed`，同会话再发消息无 409。
- 失败：一直挂着、超时后不发 resume、或会话卡在 interrupted。

## 7. 切回 deep_research，旧流程与步骤 1 完全一致

回到 <http://localhost:8001>（真实后端），设置切回 **deep_research**，再发一个问题。

- 通过：思考 Step + 流式报告与步骤 1 一致；`poetry run pytest -q` 末行仍为
  `223 passed, 4 skipped, 4 deselected`。
- 失败：旧流程混入会话端点行为、或 pytest 数量变化。

## 8. （可选）离线自检 + 代码检查

```bash
poetry run python "tests/test_agent_cases/TDM-会话前端+审批卡片/tdm_checks.py"
poetry run ruff check frontend/app.py
```

---

### 已知限制（不是缺陷）

1. 错误气泡用 `❌` 前缀 + Markdown 强调，Chainlit 消息不支持自定义气泡颜色；
   与旧端点 `/chat/stream` 的呈现方式一致。
2. 真实后端 `/chat/conversation` 目前只吐 token/tool_call/ping/error/final，
   审批中断与 `/resume` 要等 T9-2；本卡的审批交互按车道包冻结契约先行实现。
3. 审批卡片**不提供**「记住这个选择」，避免隐式放行（车道包 §3 要求）。
