## 2. 指标清单

| 指标 | 类型 | 标签 | 回答什么问题 |
|---|---|---|---|
| `agent_requests_total` | Counter | endpoint, outcome | 成功/中断/失败各多少？错误率分母 |
| `agent_request_duration_seconds` | Histogram | endpoint | 耗时分布与 p95，有没有长尾 |
| `agent_tool_decisions_total` | Counter | tool, decision | 策略 allow/deny/需审批分布，是否误杀 |
| `agent_approvals_total` | Counter | decision, outcome | 审批通过/拒绝/过期/重放/冲突 |
| `agent_errors_total` | Counter | kind | 错误集中在哪一类 |
| `agent_tokens_total` | Counter | direction | 输入/输出 token 消耗 |
| `agent_cost_yuan_total` | Counter | 无 | 累计费用（元） |

Histogram 桶：`(1, 5, 15, 30, 60, 120, 300)` 秒。

## 3. 标签纪律

标签只允许枚举值或工具名（`endpoint / outcome / tool / decision / kind / direction`）。
**禁止** `thread_id` / `session_id` / `approval_id` / 用户输入进标签：每个取值都会新增时间序列，
是 Prometheus 基数爆炸的头号原因；会话级信息走 span（trace）。
自检 TMON-4 直接扫 `/metrics` 文本，确认没有 `thread_id=` / `session_id=` / `approval_id=`。

## 4. 三条告警的阈值理由

| 告警 | 阈值 | 理由 |
|---|---|---|
| `AgentErrorRateHigh` | 错误率 > 5%，`for: 10m` | 20 题一轮里 1 题失败就是 5%；`for: 10m` 滤掉单题抖动，持续 10 分钟说明是模型/检索/网络的系统性问题 |
| `AgentLatencyP95High` | p95 > 60s，`for: 10m` | 单题评测约 30s（RAG 精排单次约 11s），p95 超 60s 已是基线两倍，说明出现长尾（重试/大检索/工具串行等待） |
| `AgentCostHourlyHigh` | 1h 费用 > 20 元，`for: 5m` | 单题成本远低于 1 元，20 元/小时相当于连续 20 题以上全价请求；`for: 5m` 排除一波尖峰，先查被刷/重试死循环 |

## 5. 开关矩阵

| ENABLE_METRICS | `/metrics` | 埋点 | 对业务的影响 |

## 7. 已知未做 / 边界

1. **多 worker 未覆盖**：默认 `REGISTRY` 在 `uvicorn --workers > 1` 下每个进程独立注册、聚合不完整；
   多 worker 需改 `prometheus_client.multiprocess`（`PROMETHEUS_MULTIPROC_DIR`），已写进模块 docstring 与文档。
2. **告警通道未接**：只交付 Prometheus 规则文件，Alertmanager 路由/通知（钉钉/邮件）未配置。
3. **token / cost 依赖 turn span**：两项只在 `ENABLE_TRACE=True` 时上报（turn 收尾才有 attrs）；
   默认 trace 关时这两个指标保持 0。这是本卡“从 turn span 的 attrs 取”的直接结果，未为此改流程。
4. **费用增量口径**：账本 `snapshot()` 是会话累计，埋点按 session 记游标后只加增量，避免多轮重复计数；
   游标只在进程内、上限 1024 会话（不进标签，符合 C1）。
5. **`rejected` / `rejected_by_user` 暂未产出**：请求在进入 SSE 生成器前就被 429/409 拒绝时，
   本卡按设计只在 `event_generator` 的 finally 记 outcome；工具侧被用户拒绝由 `agent_approvals_total`
   的 `decision="reject", outcome="rejected"` 表达。标签取值保留，后续要细分时无需改指标定义。
6. **未写台账**：`tests/test_agent_cases/台账用例.csv` 的 TMON 行由测试窗口补。
